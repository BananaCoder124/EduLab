# EduLab

Oppimateriaalipankki on opettajille suunnattu alusta, josta voi löytää, jakaa ja muokata valmiita opetusmateriaaleja. Ideana on vähentää turhaa päällekkäistä työtä ja helpottaa opettajien arkea: kaikkea ei tarvitse suunnitella ja testata alusta asti itse, jos joku on jo tehnyt toimivan materiaalin.
